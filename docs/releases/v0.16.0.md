# LAE 0.16.0 — learned segmental emphasis

LAE 0.16.0 adds real-data partial-word highlighting without changing the
presentation-neutral processing API.

## Highlights

- New `LE_MODEL_SEGMENTAL_SALIENCE` artifact type with separate learned
  predictors for unit fixation probability and normalized first-fixation
  landing position.
- New `lae-provo-segmental-v1.lem` model trained from 84 readers, 55 passages,
  and 124,158 compatible first-fixation observations in the CC BY 4.0 Provo
  Corpus.
- Partial-word spans use strict lexical cores when available and a learned,
  grapheme-safe prefix for unsegmented roots.
- English analysis now handles layered affixes and exposes unit position,
  sentence progress, and sentence unit count as stable provider-neutral
  features.
- Runtime and Python binding version 0.16.0; training package version 0.6.0;
  C ABI 1.12; model artifact format remains 1.0.

## Held-out results

Passage-grouped five-fold cross-validation selected both predictors before an
all-data refit:

- Fixation probability: MAE 0.09129, RMSE 0.11717, R² 0.73423; 48.47% RMSE
  reduction from the fold mean baseline.
- First-fixation progress: MAE 0.06805, RMSE 0.09146, R² 0.12718; 6.59% RMSE
  reduction from the fold mean baseline.

These are predictive measurements, not evidence that partial bolding improves
reading outcomes. A controlled user study remains necessary.
