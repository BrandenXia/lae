# LAE 0.15.0 — first real-data release

LAE 0.15.0 ships the first usable, data-trained English emphasis model. The
portable 100-byte `.lem` predicts word fixation probability from features
produced by the runtime's English provider; no Python or training dependency is
needed at inference time.

## What is included

- `lae-provo-fixation-v1.lem`, compatible with runtime ABI 1.11 and artifact
  format 1.0.
- A checksum-pinned, standard-library Provo trainer with deterministic
  passage-grouped five-fold selection.
- The complete candidate report, model card, attribution notice, and a minimal
  Markdown rendering example.
- Runtime and Python binding version 0.15.0; training package version 0.5.0.

## Held-out result

The selected length-plus-function ridge model was evaluated across 2,661 words
from 55 held-out passage folds and 84 readers:

| Measure | Mean-only baseline | Selected model |
| --- | ---: | ---: |
| MAE | 0.19766 | 0.09126 |
| RMSE | 0.22738 | 0.11719 |
| R² | -0.00095 | 0.73414 |

Held-out RMSE is 48.46% lower than the fold-specific mean baseline.

## Quick start

```sh
printf 'Language-aware emphasis helps readers scan complex documentation.' |
  build/le-cli --artifact models/lae-provo-fixation-v1.lem \
  --language en --threshold 0.60

PYTHONPATH=bindings/python/src python3 examples/provo_markdown.py \
  'Language-aware emphasis helps readers scan complex documentation.'
```

`0.60` is the recommended starting threshold for binary bold. Lower values
emphasize more words and higher values emphasize fewer.

## Data attribution

The model is derived from Steven G. Luke and Kiel Christianson's
[*The Provo Corpus: A Large Eye-Tracking Corpus with Predictability
Norms*](https://doi.org/10.3758/s13428-017-0908-4), available from the
[official OSF project](https://osf.io/sjefs/) under
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). LAE does not
redistribute raw participant observations or passage text.

See the [model card](https://github.com/BrandenXia/lae/blob/v0.15.0/docs/models/provo-fixation-v1.md)
for intended use,
reproduction, and limitations. Fixation probability is not a direct measure of
semantic importance, comprehension, or accessibility benefit; paired human
reading studies remain the next validation milestone.
